This repository contains my internship report and presentation from my summer internship at **COMM4 Telecom Pvt. Ltd.**, Noida, completed as part of my B.Tech (Computer Science & Engineering) curriculum at IILM University, Greater Noida.

## About the Internship

- **Organization:** COMM4 Telecom Pvt. Ltd., Noida
- **Team:** Network Operations
- **Duration:** 05 July 2026 – 31 July 2026
- **Focus areas:** Cisco networking fundamentals (routing, switching, IP addressing/subnetting) and GSM network architecture (BTS, BSC, MSC)

The internship was primarily learning-focused — building a conceptual foundation in enterprise networking and telecom architecture, along with hands-on exposure to how a network operations team functions day to day. Toward the end, I put together a short reference document consolidating what I'd learned, meant to help future interns get up to speed faster.
